# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion focused on the work.
Harassment or discriminatory behaviour of any kind is not tolerated.

Report unacceptable behaviour privately through GitHub to the maintainer
([@shellyco-code](https://github.com/shellyco-code)). Reports are handled confidentially.
